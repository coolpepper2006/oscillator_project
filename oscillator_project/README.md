# PHYS LAB — нелинейный осциллятор

Интерактивный сайт для моделирования движения тележки на нелинейно-упругой пружине. Проект разделён на **Core** (физика и численные методы) и **UI** (интерфейс, графики, таблица, экспорт).

## Что есть на сайте
- Светлая и тёмная темы; адаптивная вёрстка для мобильного экрана.
- Параметры `v₀`, `α`, `β`, `T`, `Δt`.
- Методы Эйлера, Эйлера — Кромера, Эйлера — Ричардсона и Velocity Verlet.
- Графики `x(t)`, `v(t)`, фазовый портрет `v(x)` и полной энергии `E(t)`.
- Метрики максимального смещения, максимальной скорости, ошибки энергии и числа точек.
- Таблица результатов и экспорт в CSV.
- Проверка параметров и сообщение при численной неустойчивости.

## Как запустить (Windows)
1. Скачайте ZIP и **распакуйте всю папку**, не открывайте `index.html` прямо внутри архива.
2. Установите [Visual Studio Code](https://code.visualstudio.com/) (если он ещё не установлен).
3. В VS Code выберите **File → Open Folder** и откройте папку `oscillator_project`.
4. Откройте Extensions (`Ctrl+Shift+X`), найдите расширение **Live Server** от Ritwick Dey и установите его.
5. Откройте `index.html`, нажмите правой кнопкой по редактору и выберите **Open with Live Server**.
6. Сайт откроется в браузере. Для корректной работы все папки `css`, `js` и `tests` должны оставаться внутри папки проекта.

> Важно: сайт использует JavaScript ES-модули, поэтому запуск через `file://` двойным щелчком может быть заблокирован браузером. Запускайте через Live Server.

## Физическая модель
\[
\dot{x}=v,\qquad \dot{v}=-\alpha x-\beta x^3,\qquad x(0)=0,\quad v(0)=v_0.
\]

Удельная энергия:
\[
E/m=\frac{v^2}{2}+\frac{\alpha x^2}{2}+\frac{\beta x^4}{4}.
\]

Связь с параметрами пружины: `α = k/m`, `β = b/m`. При параметрах из примера учебного материала `v₀=1`, `α=1`, `β=9`, `T=4.8`, `Δt=0.1` можно нажать пресет «Из учебника».

## Проверка Core
Тесты написаны как ES-модуль. Чтобы запустить их через Node.js (версия 18+), из папки проекта выполните:
```bash
node --experimental-default-type=module tests/core-tests.js
```
